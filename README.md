# Alternate U.S. Election Timeline Simulator (1796–2100)

A client-side simulator that generates fully divergent U.S. election timelines from 1796 to 2100.

## Features
- Starts from real historical context (Federalists vs Jeffersonian Republicans).
- Seven ideology model with drift: Revolutionary, Progressive, Liberal, Moderate, Conservative, Nationalist, Authoritarian.
- Multi-party lifecycle with creation, split, merge, decline, and survival bias for major parties.
- Crisis engine (recession, war, revolution, scandal, panic, etc.) with narrative impact.
- Electoral college + state-by-state simulation with contingent election and inversion/recount logic.
- Running mates, VP succession, assassination risk, dictatorship rise/fall, impeachment checks.
- Economy/polarization/debt loops with long-memory effects and third-party surge conditions.
- Year-by-year events tab, party evolution tab, and full story tab.

## Run
Open `index.html` in a browser.
